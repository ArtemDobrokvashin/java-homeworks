# Класс `Bank`

Банк с ограниченным капиталом (1000 руб.). Управляет счетами, следит, чтобы сумма на всех счетах не превышала лимит.

## Основные методы

- **`createAccount(String number, double initial)`**  
  Создаёт счёт, если хватает средств у банка.

- **`transferMoney(String from, String to, double amount)`**  
  Переводит деньги между счетами.

- **`closePartOfAccount(String number, double amount)`**  
  Снимает указанную сумму со счёта (освобождает место в лимите).

- **`showAccountsMoney(String number)`**  
  Показывает баланс указанного счёта.

- **`freeMoney()`**  
  Выводит общую сумму денег на всех счетах.

- **`getTotalBalance()`**  
  Возвращает максимальный капитал банка (1000).

> Все операции проходят через банк. Прямое изменение баланса счетов извне невозможно благодаря инкапсуляции.
