## Ответы на теоретические вопросы

### 1. Определения понятий
* **Класс** — это шаблон или чертеж для создания объектов. Он описывает состояние (поля) и поведение (методы), которые будут у всех объектов, созданных на его основе.
* **Конструктор** — это специальный метод, который автоматически вызывается в момент создания объекта (с помощью оператора `new`). Его главная задача — инициализировать объект и задать ему начальные значения. Имя конструктора всегда совпадает с именем класса.
* **Параметры конструктора** — это переменные, которые передаются в конструктор при создании объекта. Они позволяют «настроить» объект, передав ему необходимые начальные данные.
* **Метод** — это функция, описанная внутри класса. Методы определяют поведение объекта, то есть описывают действия, которые объект может выполнять.

### 2. Количество конструкторов в классе
У класса может быть **неограниченное количество** конструкторов. Это называется *перегрузкой конструкторов*. Чтобы компилятор мог их различать, они должны иметь разную сигнатуру (отличаться количеством или типами параметров). Если конструктор не объявлен явно, Java автоматически создает конструктор по умолчанию без параметров.

### 3. Сигнатура метода и возвращаемое значение
* **Сигнатура метода** — это его уникальная идентификация, которая состоит из **имени метода** и **списка типов его параметров** (в порядке их следования).
* **Является ли возвращаемое значение частью сигнатуры?** Нет, возвращаемый тип (return type) **не входит** в сигнатуру метода. Компилятор Java различает методы исключительно по имени и параметрам.

### 4. Ключевое слово `void`
* **`void`** (в переводе «пустой») — это ключевое слово, которое используется в качестве возвращаемого типа метода.
* **Для чего нужно:** Оно указывает на то, что метод выполняет какие-либо действия (например, выводит текст на экран или изменяет поля объекта), но **не возвращает** никакого значения (результата) обратно в вызывающий код.

### 5. Область видимости (Scope)
* **Область видимости** — это часть программы, в которой переменная или метод существуют и к которым можно обратиться по имени.
* **Какие области видимости существуют:** В Java выделяют области видимости на уровне класса (поля класса), на уровне метода (локальные переменные) и на уровне блока кода (переменные внутри циклов `for`, `while` или условий `if`). Также существуют модификаторы доступа (`public`, `private`, `protected`), которые ограничивают видимость элементов класса для других классов.
* **Чем может быть ограничена:** Область видимости локальных переменных в Java жестко ограничена **фигурными скобками `{}`** того блока кода, в котором они были объявлены. Как только выполнение программы выходит за закрывающую скобку `}`, переменная перестает существовать.

### 6. Ключевое слово `this`
* **`this`** — это ссылка на **текущий объект**, от имени которого был вызван метод или конструктор.
* **Для чего нужно:** Чаще всего оно используется для разрешения конфликта имен, когда имя параметра метода совпадает с именем поля класса (например, `this.name = name`). Также `this` используется для вызова одного конструктора из другого (`this(...)`) и для передачи текущего объекта в качестве аргумента в другой метод.
