**Зачем нужно слово `super` в Java?**  
`super(name)` вызывает конструктор родительского класса, чтобы передать ему параметры и правильно инициализировать унаследованные поля (например, `name`). Без этого поля в родителе останутся `null` или `0`.

**Есть ли в Java множественное наследование?**  
Нет. Класс может наследоваться только от одного класса. Это сделано для предотвращения неоднозначности (например, если два родителя содержат метод с одинаковым именем).

**Как объяснить такую конструкцию и почему такое возможно?**
```java
public interface Dog extends Mammal, Animal { }
```  
Интерфейсы могут наследоваться от нескольких интерфейсов одновременно. Это разрешено, потому что интерфейсы не содержат состояния и реализации — только объявления методов. Поэтому конфликтов не возникает.
