**Как измеряется сложность алгоритмов?**  
Сложность измеряется с помощью **О-нотации** (Big O), которая описывает поведение алгоритма при росте входных данных — по времени (временная сложность) и памяти (пространственная сложность).

**Какие ограничения есть при использовании бинарного поиска?**  
Массив **должен быть отсортирован**. Бинарный поиск не работает на неупорядоченных данных.

**Какая сложность вставки, поиска и удаления в ArrayList, LinkedList, HashMap?**
- **ArrayList**:
    - Поиск по значению — O(n)
    - Доступ по индексу — O(1)
    - Вставка/удаление в конце — O(1), в середине — O(n)
- **LinkedList**:
    - Поиск — O(n)
    - Вставка/удаление (если известна позиция) — O(1), но поиск позиции — O(n)
- **HashMap**:
    - Вставка, поиск, удаление — в среднем **O(1)**, в худшем случае — O(n)

**Что такое рекурсия?**  
Рекурсия — это когда метод **вызывает сам себя**, чтобы решить задачу, разбивая её на более мелкие подзадачи. Обязательно должен быть **базовый случай** (условие выхода).

**Что такое динамическое программирование?**  
Это метод решения сложных задач путём **разбиения на подзадачи** и **сохранения результатов** уже решённых подзадач, чтобы не вычислять их повторно («запоминание» → memoization).

**Что такое графы? Для чего они используются?**  
Граф — это структура из **вершин** (узлов) и **рёбер** (связей между ними). Используется для моделирования отношений: маршруты, соцсети, зависимости, лабиринты, деревья решений и т.д.
