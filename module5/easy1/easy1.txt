
Дайте определения понятиям: массив, индекс в массиве, двумерный и многомерные массивы, цикл.

Массив — это упорядоченный набор элементов одного типа, хранящихся в памяти подряд. Например, int[] arr = new int[5]; создаёт массив из 5 целых чисел.
Индекс в массиве — это номер элемента в массиве. Отсчёт всегда начинается с 0. То есть первый элемент — arr[0], второй — arr[1].
Двумерный массив — это «массив массивов», таблица со строками и столбцами. Объявляется как int[][] matrix = new int[3][4]; (3 строки, 4 столбца).
Многомерный массив — обобщение: массив с тремя и более измерениями (например, int[][][] cube = new int[2][3][4];).
Цикл — конструкция, которая повторяет блок кода несколько раз, пока выполняется условие.

В чем различие между do-while и while?

Разница между do-while и while
while — сначала проверяет условие, потом выполняет тело. Если условие сразу false, тело не выполнится ни разу.
do-while — сначала выполняет тело один раз, потом проверяет условие. Тело выполнится минимум один раз, даже если условие ложно.

Что такое в цикле for int i = 0, i < n и i++ ?

int i = 0 — Старт (начинаем с нуля).
i < n — Условие (пока не дошли до конца).
i++ — Шаг
