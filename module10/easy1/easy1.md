**1. Полиморфизм** — способность объектов разных типов обрабатываться через единый интерфейс, при этом каждый тип реализует поведение по-своему.

**2. Отличие:**
- **Абстрактный класс** — может содержать реализацию методов и поля; используется для *частичного* общего поведения ("is-a").
- **Интерфейс** — только контракт (методы без реализации до Java 8); используется для *возможностей* ("can-do").  
  → Используй **абстрактный класс**, если есть общая реализация.  
  → Используй **интерфейс**, если нужно множественное наследование или задать поведение без реализации.

**3. Нельзя создать экземпляр ни абстрактного класса, ни интерфейса.**

**4. Анонимные классы** — классы без имени, создаваемые «на лету» для реализации интерфейса или расширения класса. Применяются для одноразовых реализаций (например, обработчиков событий).

**5. Интерфейсы без методов** — это **маркеры** (например, `Serializable`). Они «отмечают» класс, сообщая JVM или другим частям программы: «этот объект обладает определённым свойством».

**6. Обобщённые типы (Generics)** — механизм, позволяющий работать с типами безопасно и гибко (например, `List<String>`), избегая приведения типов и ошибок времени выполнения.

**7. Ограничение типов:**
- **Сверху (`<T extends Animal>`)** — T должен быть подтипом `Animal`.
- **Снизу (`<? super Dog>`)** — тип должен быть надтипом `Dog` (редко используется, чаще в PECS).
