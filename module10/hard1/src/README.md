# rogalik

Альфа-версия текстовой RPG-игры в жанре рогалик.

## Особенности (на текущем этапе):
- Случайная генерация подземелья из 3 комнат
- Три типа комнат: битва, ловушка, исцеление
- Интерактивный бой с промахами, критическими ударами и защитой
- Выбор оружия при старте (меч, копьё, пистолет)
- Гоблины с случайным оружием и системой прокачки (в разработке)
