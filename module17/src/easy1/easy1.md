MVC — архитектурный паттерн, разделяющий приложение на Model (логика), View (интерфейс) и Controller (обработка ввода).
MVC отличается тем, что это составной паттерн, объединяющий другие паттерны для разделения ответственности в UI-приложениях.
Model хранит данные и бизнес-логику, View отображает информацию, Controller обрабатывает действия пользователя и связывает Model с View.
Пакет Swing используется для создания графических интерфейсов в Java-приложениях (окна, кнопки, поля ввода).
Анонимные классы — классы без имени, создаваемые на месте для краткой реализации интерфейсов (например, обработчиков событий).
